# Fargonam

Farg'ona vodiysi uchun super-app — taksi, marketplace, yangiliklar.

## Modullar
- **Marketplace** (birinchi MVP — qurilmoqda)
- Taksi (keyinroq)
- News & Social (keyinroq)
- To'lov (MVP'dan keyin)

## Tech Stack
- **Mobile**: Flutter (Android + iOS)
- **Backend**: FastAPI (Python)
- **Database**: PostgreSQL + Redis
- **Deploy**: Docker, Linux

## Tuzilishi
```
fargonam/
├── backend/         # FastAPI server
├── mobile_user/     # Foydalanuvchi ilovasi (Flutter)
├── mobile_seller/   # Sotuvchi/Haydovchi ilovasi (Flutter)
├── admin_web/       # Admin panel
└── docs/            # Hujjatlar
```
